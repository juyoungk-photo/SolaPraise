# Branding assets

## The mark

Three C's, nested and turned to face upward. Read one way they are the
church's initials; read the other they are hands open to receive, which is
what the gold dot above them is for — the thing being received rather than
anything the hands are doing. It replaced two literal hands because that
drawing said "praise" and nothing else; this one says whose.

Generated by `Tools/make-icon.py` so the icon and the consent logo are the
same artwork and cannot drift apart.

## consent-logo-120.png

The logo for Google's OAuth consent screen, so the screen a teammate sees
when signing in carries the same mark as the app they are signing in to.

Google's requirements: square, 120×120, JPG/PNG/BMP. Regenerate both sizes
with:

    python3 Tools/make-icon.py

### Before uploading it

Uploading a logo to an External app that is published triggers **brand
verification** — a Google review, which also wants a homepage and a privacy
policy on a domain we control. Publishing the consent screen WITHOUT a logo
needs none of that, and publishing is the part that matters: it ends the
7-day refresh token expiry that makes everyone sign in again weekly.

So the order is: publish first, add the logo later if the review is worth it.
